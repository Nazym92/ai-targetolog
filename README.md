# Сайт курса «ИИ-таргетолог» — как редактировать

## Структура папки

```
site/
├── index.html      ← все тексты сайта (по блокам, с комментариями)
├── css/styles.css  ← дизайн: цвета, шрифты, отступы
├── js/config.js    ← куда ведёт кнопка «Записаться» (WhatsApp / ссылка)
├── js/main.js      ← анимации, меню, аккордеоны, форма (обычно не трогать)
├── images/         ← фото автора (author.jpg) и иконка сайта (favicon.svg)
├── robots.txt      ← для поисковиков
└── sitemap.xml     ← для поисковиков
```

## Как поменять тексты
Откройте `index.html` в любом текстовом редакторе (например, VS Code или TextEdit в режиме простого текста).
Каждый блок отмечен заголовком-комментарием, например:
`<!-- ================= 4. ПРОГРАММА КУРСА ================= -->`.
Меняйте текст между тегами, сами теги (`<li>`, `<h3>`, `<p>`) не удаляйте.

- **Добавить пункт в модуль** — скопируйте строку `<li>…</li>` внутри нужного модуля.
- **Добавить вопрос в FAQ** — скопируйте целиком блок `<div class="faq__item reveal">…</div>`.

## Как поменять стоимость
1. В `index.html` найдите `price__amount` — там `29 900`, рядом `price__old` — старая цена `69 000`, а `price__promo` — текст «до 28 ноября».
2. В том же файле в начале (блок `application/ld+json`) поменяйте `"price": "29900"` и `"priceValidUntil"`.
3. В окне заявки найдите `ИИ-таргетолог · 29 900 тенге`.
4. В `js/config.js` поменяйте `price`.

## Как поменять фото
Положите новое фото в папку `images/` с именем `author.jpg` (вертикальное, ~1400 px по высоте, до 300 КБ).

## Как поменять цвета
В начале `css/styles.css`, блок `:root`: `--violet`, `--blue`, `--bg` и градиенты `--grad`, `--grad-btn`.

## Кнопки «Записаться на курс» и «Оплата»
- «Записаться на курс» открывает WhatsApp +7 776 427 36 78 с готовым сообщением. Номер и текст меняются в `js/config.js` (строка `enrollLink`).
  Если очистить `enrollLink` (оставить `""`), вместо WhatsApp снова откроется форма заявки (демо, данные никуда не отправляются).
- «Оплата» ведёт на Kaspi: https://pay.kaspi.kz/pay/xpdiifes — ссылка в `index.html`, ищите `price__pay`.
